# 🚀 太空戰機：星際決戰 (Space Fighter: Galactic Showdown)

一部基於網頁瀏覽器打造的經典太空射擊遊戲！玩家將駕駛先進戰機，在浩瀚星際中迎擊湧入的敵機，體驗刺激的街機風格空戰。

---

## 🎮 遊戲玩法與視覺風格

* **視覺呈現**：採用經典大型電玩（Arcade）風格，搭配流暢的星空背景捲軸與華麗的粒子爆炸特效，營造沉浸感的太空戰場。
* **核心玩法**：玩家操控戰機在畫面上靈活移動，躲避敵方子彈與隕石襲擊，同時利用連續火力擊毀敵機累積高分。隨時間推進，敵人的數量與攻擊頻率將逐漸提升，考驗玩家的反應與極限操作。

---

## 🤖 使用的 AI 提示詞 (Prompts)

本專案在開發過程中借助 AI 工具輔助設計，主要使用的 Prompt 如下：

> **核心架構與邏輯：**
> *"請幫我使用 HTML5 Canvas 與 JavaScript 寫一個 2D 太空射擊遊戲『太空戰機：星際決戰』。需要包含玩家戰機、敵機生成、子彈發射機制、碰撞檢測（Collision Detection）、分數計算與 Game Over 判定。請確保代碼結構清晰且模組化。"*

> **遊戲視覺與粒子系統：**
> *"請為遊戲加入動態星空背景（Starfield）捲軸效果，並在敵機被擊毀時加入粒子爆炸（Particle Explosion）特效，提升遊戲的打擊感與視覺效果。"*

> **控制與優化：**
> *"請實現鍵盤（WASD / 方向鍵 + 空格鍵）的操作響應，並優化 `requestAnimationFrame` 遊戲循環，確保在不同螢幕上都能平滑運行。" *

---

## ✅ 已完成的功能

* [x] **玩家控制系統**：平滑的戰機移動與自動/手動發射子彈機制。
* [x] **敵機與障礙生成**：動態刷出不同類型的敵機與星際隕石。
* [x] **精準碰撞檢測**：實時計算玩家、敵機與子彈之間的邊界碰撞（AABB / 圓形碰撞）。
* [x] **計分與生命系統**：紀錄當前得分，並設有生命值（HP）或血條機制。
* [x] **動態視覺特效**：包含深空背景星流捲軸與敵機炸裂粒子系統。
* [x] **遊戲狀態管理**：完整支援遊戲開始、暫停、Game Over 結算與重新開始功能。

## 🕹️ 操作方式

| 按鍵 / 操作 | 功能說明 |
| :--- | :--- |
| **`W` / `↑`** | 戰機向上移動 |
| **`S` / `↓`** | 戰機向下移動 |
| **`A` / `←`** | 戰機向左移動 |
| **`D` / `→`** | 戰機向右移動 |
| **`Space` (空格鍵)** | 發射雷射子彈 |
| **`P`** | 暫停 / 繼續遊戲 |
